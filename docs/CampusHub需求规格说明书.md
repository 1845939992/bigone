## 2 概述

### 1.1 背景

- **系统名称**：CampusHub校园社区系统
- **任务提出者**：课程设计项目小组
- **开发背景**：

随着移动互联网技术的发展，大学生越来越倾向于通过移动端进行学习交流、校园生活分享以及兴趣讨论。目前常见的社区平台如贴吧、知乎等虽然功能完善，但缺少专门面向校园学生群体的交流环境。

为了满足大学生日常交流与信息分享的需求，开发一款专门面向高校学生的移动社区平台具有较强的现实意义。本系统以Android平台为基础，提供帖子发布、浏览、评论、收藏、点赞以及个人信息管理等功能，方便学生之间进行学习经验交流、校园生活讨论以及兴趣分享。

CampusHub校园社区系统具有操作简单、界面友好、功能实用等特点，能够为校园用户提供一个便捷的移动交流平台。

**开发所使用的技术栈：**

1. 开发工具：Android Studio
2. 开发语言：Java，XML
3. 数据库：MySQL

- **开发者**：课程设计开发小组
- **用户**：高校学生用户

### 1.2 目的

编写本软件需求规格说明书的目的在于使用户与开发人员双方对CampusHub校园社区系统的功能和需求达成一致理解，并作为后续系统设计、系统开发与系统测试的重要依据。

- 本文档面向用户代表、系统分析人员、开发人员以及测试人员；
- 从软件设计角度明确系统功能与系统行为；
- 为系统后续开发与验收提供参考依据。

### 1.3 范围

本系统主要实现以下功能：

1. 实现用户注册、登录、自动登录以及密码修改功能；
2. 实现社区帖子浏览、发帖、评论、点赞与收藏功能；
3. 实现帖子搜索功能；
4. 实现用户个人中心功能，包括查看我的帖子、我的收藏以及编辑个人信息；
5. 实现校园学生之间的信息交流与互动功能。

本系统仅支持Android手机客户端，不提供Web管理后台功能。

### 1.4 假设

1. 本系统默认所有用户均为校园学生用户；
2. 本系统不考虑管理员后台管理功能；
3. 本系统暂不考虑复杂的系统安全机制；
4. 本系统不考虑高并发情况下的性能优化问题；
5. 本系统不考虑数据自动备份与恢复功能；
6. 本系统默认用户设备具备正常网络连接。

### 1.5 业务术语

| 术语 | 解释 |
|------|------|
| 帖子 | 用户在社区中发布的内容，可包含文字和图片 |
| 评论 | 用户对帖子内容进行回复与讨论 |
| 二级回复 | 用户对评论内容进行再次回复 |
| 收藏 | 用户将感兴趣的帖子保存至个人收藏列表 |
| 点赞 | 用户对帖子内容表示支持 |
| 自动登录 | 再次打开时无需重复输入账号密码 |
| 我的收藏 | 已收藏的帖子列表 |

## 3 系统功能概述

### 2.1 用户模块

#### 用户模块说明

用户模块主要实现用户身份认证与账号管理功能，包括注册、登录、自动登录、密码修改以及退出登录等功能。

### 2.2 社区模块

#### 社区模块说明

社区模块是系统核心模块，主要负责帖子浏览、发帖、点赞以及收藏等功能，实现用户之间的信息交流与互动。

### 2.3 评论模块

#### 评论模块说明

评论模块主要负责帖子评论与用户互动交流功能，支持普通评论以及评论回复功能。

### 2.4 搜索模块

#### 搜索模块说明

搜索模块支持用户根据帖子标题快速查找相关帖子内容。

### 2.5 个人中心模块

#### 个人中心模块说明

个人中心模块提供用户个人信息管理功能，包括查看个人资料、修改个人信息、查看我的帖子、查看我的收藏以及修改密码等功能。

## 7 非功能性需求

### 7.1 系统性能需求

#### （1）时间特性

系统页面响应时间达到移动应用基本使用要求，一般操作响应时间不超过3秒。

#### （2）并发能力

系统允许不少于100个用户同时在线访问。

### 7.2 系统安全性

1. 用户必须登录后方可进行发帖、评论、点赞以及收藏操作；
2. 用户账号与密码信息存储于数据库中；
3. 本系统暂不实现复杂安全验证机制。

### 7.3 可维护性需求

1. 系统采用模块化设计，便于后续维护与功能扩展；
2. 源代码需具有完整注释；
3. 系统功能模块划分清晰。

### 7.4 可扩展性

系统采用分模块开发方式，后续可扩展：

1. 帖子分类功能；
2. 消息通知功能；
3. 管理员后台功能；
4. 好友与私信功能；
5. 多平台支持功能。

### 7.5 可移植性需求

本系统运行于Android平台，具备一定的平台兼容能力，可在主流Android设备上正常运行。数据库不做可移植性需求。

### 7.6 数据存储需求

系统数据统一存储于MySQL数据库中，包括：

1. 用户信息；
2. 帖子信息；
3. 评论信息；
4. 收藏信息；
5. 点赞信息。

### 7.7 用户界面

1. 系统采用移动端可视化图形界面；
2. 界面设计简洁、美观，符合校园用户使用习惯；
3. 主要功能操作需提供相应提示信息；
4. 页面布局清晰，操作流程简单易懂；
5. 系统界面适配主流Android手机屏幕尺寸。
